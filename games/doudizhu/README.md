# 斗地主

单人对战两名电脑玩家的网页版经典斗地主。

## 已实现

- 完整叫分流程：三位玩家依次选择不叫或 1～3 分，无人叫分时自动重新发牌。
- 地主获得三张底牌并先手出牌；两位农民为同一阵营。
- 支持单张、对子、三带、顺子、连对、飞机、四带二、炸弹和王炸。
- 炸弹、王炸与春天自动翻倍，并按地主/农民身份结算积分。
- 电脑玩家会估牌叫分、配合队友，并避免在非关键时刻浪费炸弹。
- 本地保存胜局、总局数、积分、连胜和最高连胜。
- 支持键盘、鼠标和触屏操作，并提供明确的可出牌状态提示。

## 操作

- 点击手牌：选择或取消选择
- `Space`：出牌
- `H`：提示
- `P`：不出

## 本地运行

```bash
npm install
npm run dev
```

默认地址：<http://localhost:3001/>
