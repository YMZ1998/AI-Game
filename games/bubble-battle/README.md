# 泡泡堂

一款基于 React、Canvas 和 vinext 的泡泡堂风格网页游戏。

玩家需要在水上街区移动、放置泡泡、炸开箱子并收集强化道具，用十字水花击败全部捣蛋怪。水花会伤到自己，放泡泡前记得留好退路。

## 游戏模式

- 单人闯关：挑战主动追击和放泡泡的电脑角色，收集九种强化道具并进入下一张地图。
- 本地双人：两名玩家共享一台设备公平对战，不生成电脑角色与随机道具，最后存活者获胜。

## 操作

- 方向键或 `WASD`：移动
- 空格键：放置泡泡
- `E`：引爆场上的遥控泡泡
- 双人 P1：`WASD` 移动，`F` 放置泡泡
- 双人 P2：方向键移动，`Enter` 放置泡泡
- 触屏设备：使用页面下方方向键和泡泡按钮

## 道具

- 速度鞋、水花范围、额外泡泡：永久强化本局能力
- 护盾：抵挡一次敌人碰撞或水花伤害，最多叠加两层
- 加时钟：立即增加 15 秒
- 冰冻：让全部捣蛋怪减速 8 秒
- 遥控器：让下一颗泡泡变成遥控泡泡，可按 `E` 主动起爆
- 磁铁：10 秒内扩大所有道具的拾取范围
- 爱心：恢复一条生命

## 环境要求

- Node.js `>=22.13.0`

## 本地运行

```bash
npm install
npm run dev
```

## 构建与测试

```bash
npm run build
npm test
```

## 主要目录

- `app/`：游戏界面、绘制和核心玩法
- `public/`：分享图片与静态资源
- `tests/`：服务端渲染测试
- `.openai/hosting.json`：Sites 托管配置
